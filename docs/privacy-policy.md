# Personal OS privacy policy

Personal OS is a private, single-user application. It processes only data the
owner submits or explicitly authorizes.

Cloudflare D1 in the configured EU location stores canonical structured data.
Document originals are encrypted in the browser before private EU-jurisdiction
R2 storage; plaintext and the vault passphrase are not transmitted. Database
backups are encrypted with a separate server-side key before R2 storage.

The private GPT receives minimized summaries and can create proposals. It
cannot confirm records, delete data, execute SQL, obtain encrypted originals or
control integrations. Masked document excerpts require explicit authorization
and expire automatically.

Technical logs exclude request bodies and personal health or financial values.
Audit records are append-only. The owner can revoke the GPT service token,
browser sessions, upload grants, excerpts and Calendar authorization.

No advertising analytics are used. Security incidents must be reported to the
private repository owner without attaching personal documents or secrets.
